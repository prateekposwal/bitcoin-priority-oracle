API Documentation
REST endpoints for live Bitcoin data.
All endpoints return JSON. Base URL: https://mempool.space/api
Fee Estimates
GET/v1/fees/recommended
Returns fastestFee, halfHourFee, hourFee, economyFee, minimumFee in sat/vB.
GET/v1/fees/mempool-blocks
Fee histogram for the next mempool blocks — predicts near-term fee pressure.
Mempool & Blocks
GET/mempool
Mempool snapshot: count, vsize, total fee, fee histogram.
GET/blocks?limit=10
Recent blocks with height, size, weight, tx count, fee data.
GET/blocks/tip/height
Current block height (plain text).
Mining & Lightning
GET/v1/mining/blocks/fees/24h
Fee revenue history for the last 24 hours, per block.
GET/v1/lightning/statistics/latest
LN network stats: channel count, node count, total capacity.
GET/v1/difficulty-adjustment
Difficulty adjustment info: change, estimated retarget height.
