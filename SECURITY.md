# Security Policy

## Reporting a Vulnerability

We take the security of Bitcoin Sahi and related projects seriously. 
If you believe you've found a security vulnerability, please report it.

**Please do NOT report security vulnerabilities via public GitHub issues, Reddit, or Discord.**

Instead, email: [bitcoin-sahi-security@googlegroups.com](mailto:bitcoin-sahi-security@googlegroups.com)

You should receive a response within 48 hours. If you don't, please follow up.

## What to include
- Description of the vulnerability
- Steps to reproduce
- Affected versions/files
- Any potential impact

## Scope
- The Bitcoin Sahi website (bitcoinsahi.com)
- The UTXO cost model and research scripts
- The live data pipeline and monitoring tools
- The research documentation and verification appendix

## Out of scope
- Third-party APIs we consume (mempool.space, blockchain.info, blockstream.info) — report to those projects directly
- The Bitcoin protocol itself — report to bitcoin-dev mailing list

## Response Timeline
- 48h: Initial acknowledgment
- 7 days: Assessment and mitigation plan
- 30 days: Fix deployed (depending on complexity)

## Thanks
We appreciate responsible disclosure and will acknowledge contributions in our articles page (unless you prefer to remain anonymous).
